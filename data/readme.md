## Có cần docs mô tả tài liệu không?

**Có, bắt buộc.** Mỗi người phải nộp một file catalog để ngày mai bạn không phải mở từng PDF để nhập tay metadata.

Tạo hai file:

```text
data/bronze/metadata/international_documents.csv
data/bronze/metadata/vietnam_documents.csv
```

Mỗi tài liệu một dòng. Đây chính là “docs mô tả tài liệu” phục vụ bước parsing, chunking, embedding và citation sau này.

### Schema bắt buộc

| Trường | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `document_id` | string | Có | ID duy nhất, ví dụ `eu_ai_act_2024_1689` |
| `title` | string | Có | Tên đầy đủ văn bản |
| `source_org` | string | Có | Cơ quan ban hành, ví dụ `European Union`, `NIST`, `Chính phủ Việt Nam` |
| `source_url` | string | Có | Trang chính thức chứa văn bản |
| `download_url` | string | Có | URL tải trực tiếp file |
| `file_path` | string | Có | Đường dẫn tương đối trong repo |
| `file_format` | string | Có | `pdf`, `html`, `xml`, `docx` |
| `language` | string | Có | `en`, `vi` |
| `doc_type` | string | Có | `regulation`, `law`, `strategy`, `guideline`, `standard`, `recommendation` |
| `published_date` | date | Có nếu có | Ngày ban hành |
| `version_date` | date | Có | Ngày phiên bản đang lưu |
| `effective_date` | date | Có nếu có | Ngày có hiệu lực |
| `status` | string | Có | `current`, `superseded`, `draft`, `guideline` |
| `jurisdiction` | string | Có | `EU`, `US`, `VN`, `Global`, `ASEAN` |
| `topics` | string | Có | Chủ đề, phân tách bằng `;` |
| `license` | string | Có | `Public domain`, `CC-BY`, `Unknown` |

## Script bắt buộc để tạo checksum

Đưa đoạn này vào repo để hai bạn chạy sau khi tải file:

```python
import hashlib
import csv
from pathlib import Path

def sha256_file(path: str) -> str:
    sha256 = hashlib.sha256()
    with open(path, "rb") as f:
        for block in iter(lambda: f.read(8192), b""):
            sha256.update(block)
    return sha256.hexdigest()

def add_checksum_to_csv(csv_path: str):
    rows = []
    with open(csv_path, newline="", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        fieldnames = reader.fieldnames
        for row in reader:
            file_path = row["file_path"]
            if Path(file_path).exists():
                row["checksum_sha256"] = sha256_file(file_path)
                row["file_size_bytes"] = Path(file_path).stat().st_size
            else:
                raise FileNotFoundError(file_path)
            rows.append(row)

    with open(csv_path, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(rows)

add_checksum_to_csv("data/bronze/metadata/international_documents.csv")
add_checksum_to_csv("data/bronze/metadata/vietnam_documents.csv")
```

## Nguyên tắc chấm đạt

Một tài liệu chỉ được tính là **đạt** khi có đủ 4 thứ:

1. File gốc PDF/HTML/XML/DOCX.
2. URL nguồn chính thống.
3. Một dòng metadata hoàn chỉnh.
4. SHA-256 checksum.

Nếu thiếu một trong bốn thứ, coi như **chưa nộp**.
